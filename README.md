
# 🔢 Simple Calculator

A basic and responsive calculator built using **HTML, CSS, and JavaScript**.
It supports mouse clicks and keyboard input for convenient usage.
Styled with a minimal orange-themed UI.

---

## 🚀 Features

✔️ Basic arithmetic operations (+, −, ×, ÷, %)
✔️ Keyboard support (Enter, Esc, Backspace, operators, numbers)
✔️ Attractive Orange UI buttons
✔️ Error handling for invalid expressions
✔️ Responsive and lightweight design
